# 0단계 작업 사양

0단계 1인 테스트 버전의 작업 지시서다. 원본 프롬프트(아래 B)는 초기 PRD를 기준으로 작성되었으므로, PRD와 충돌하면 A의 정리(최신 PRD)를 따른다.

## A. 충돌 정리와 확정 사항 (2026-10-28)

| 항목 | 원본 프롬프트 | 적용 |
| --- | --- | --- |
| 저장 | localStorage | IndexedDB (idb-keyval), 세이브 버전 번호 + 마이그레이션 |
| 해상도·크기 | 언급 없음 | 640×360 내부 해상도, PRD 11장 크기 기준표 |
| 몬스터 외형 | 언급 없음 | 코드 그래픽에도 PRD 8장 오염 변이 규칙 적용 |
| 기술 구성 | Phaser 3 + TS + Vite | 동일 + Preact 오버레이, zod, Vitest, pnpm 워크스페이스 |
| 변이 게 주 드롭 | 각반·발 | 손·무기 (PRD 특징 부위 = 비대한 집게) |
| 맵 | (PRD는 Tiled) | 외부 에셋 없이 data 파일의 구역 정의로 생성. Tiled는 이후 |

**확정 규칙**

- **50 배수 돌파 시도**: 성공 시 결과가 50의 배수에 도달하는 모든 시도. 예: 48에서 희귀(+3) 시도가 실패해도 하락 적용.
- **사망 페널티 소수점**: 감소량은 올림, 강화 수치가 1 이상이면 최소 1 감소.
- **디버그**: `config.json`의 `debug` 블록으로 디버그 버튼 표시 여부와 재료 지급 수량·부위·등급을 조정한다. 디버그 창에서 재료 지급, 장비 지급, 강화 수치 설정, 탑 층 해금, 퀘스트 건너뛰기.

**진행 방식**: 마일스톤마다 자체 테스트(타입 검사, 단위 테스트, 빌드, 브라우저 자동 실행) 후 다음 단계로 진행. 완료 보고서에 오류 횟수, 내용 요약, 보완 방향 포함.

## B. 원본 프롬프트

픽셀 아트 쿼터뷰 MMORPG "타워 브레이크(가제)"의 0단계 1인 테스트 버전을 만들어줘.
서버나 멀티플레이 없이, 브라우저에서 혼자 핵심 루프(사냥·퀘스트 → 재료 획득 → 부위 강화 → 더 강한 지역과 탑 도전)가 돌아가는지 검증하는 것이 목표야.

### 진행 방식
- 코드를 쓰기 전에 폴더 구조, 데이터 구조, 아래 마일스톤별 구현 계획을 먼저 보여주고 내가 확인하면 진행해
- 마일스톤 하나가 끝날 때마다 실행해서 동작을 확인하고, 무엇을 만들었는지 요약한 뒤 다음으로 넘어가
  1) 기본 틀: 세력 선택, 쿼터뷰 맵, 이동, 저장
  2) 전투와 몬스터, 재료 드롭
  3) 부위 강화 시스템 전체
  4) 거점 NPC와 퀘스트
  5) 탑 1~10층

### 기술 조건
- 웹 브라우저 게임 (PC + 모바일 웹). 앱 빌드는 하지 않음
- Phaser 3 + TypeScript + Vite 권장 (더 나은 선택이 있으면 이유와 함께 제안)
- 외부 이미지 에셋 없이 시작: 캐릭터·몬스터·타일은 코드로 그린 픽셀 스타일 임시 그래픽
- 저장은 브라우저 localStorage (세력, 부위 강화 수치, 장비, 인벤토리, 퀘스트 진행, 탑 진도)
- 몬스터, 퀘스트, 탑 층, 강화 확률 등 모든 게임 데이터와 수치는 data/config 파일로 분리해서 코드 수정 없이 조정할 수 있게

### 세계관 (화면 텍스트용 요약)
거대한 탑이 나타나고 탑 브레이크로 지구 생명의 50%가 소멸했다.
탑 주변은 오염되어 변이 몬스터가 상주한다. 생존자는 두 세력으로 나뉘어 몸을 강화해 싸운다.
탑 안에는 지능이 높은 외계 관리자들이 층마다 몬스터를 부린다.

### 1. 세력 선택
- 시작 화면에서 두 세력 중 하나 선택 (선택 후 변경 불가, 새로 시작하기로만 초기화)
- 메카닉: 몸을 로봇으로 대체. 원거리 공격 특화 (투사체 발사). 무기·방어구 장착 가능
- 유전공학: 몬스터 세포로 몸을 강화. 근접 공격 특화 (손 무기화 공격). 장비 착용 불가, 강화만

### 2. 월드 (쿼터뷰/아이소메트릭)
- 세력별 거점 2곳: 메카닉 거점, 유전공학 거점. 각 거점은 안전지대이며 자기 세력 거점에만 들어갈 수 있음
- 오염 지역 2곳: 정글, 해협. 지역마다 오염 농도가 다름 (config 값, 해협이 더 높게)
- 탑 입구 1곳: 두 오염 지역 사이에 배치
- PC: WASD/방향키 이동, 마우스 클릭 또는 스페이스 공격
- 모바일 웹: 왼쪽 가상 조이스틱 + 오른쪽 공격 버튼

### 3. 몬스터 (지역별 소형 2종, 중형 2종, 대형 1종 = 총 10종)
- 정글: 소형 변이 독개미, 가시덩굴 새싹 / 중형 변이 원숭이, 독거미 / 대형 식인 거대꽃
- 해협: 소형 변이 게, 독해파리 / 중형 가시 장어, 갑옷 거북 / 대형 변이 상어
- 크기가 클수록 체력·공격력·드롭 등급이 높음. 대형은 리스폰이 느린 지역 보스급
- 해협 몬스터는 정글보다 전반적으로 강함
- 이름과 수치는 data 파일에 두고 기본값은 네가 제안

### 4. 재료
- 메카닉은 "부품", 유전공학은 "세포"를 획득
- 재료는 부위별로 구분됨 (머리용, 팔용 등). 몬스터마다 주로 드롭하는 부위 재료가 다름 (예: 원숭이 = 팔, 게 = 각반·발)
- 재료 등급: 일반 / 고급 / 희귀 / 전설. 드롭률은 몬스터 크기와 지역에 따라 다르게 (기본값은 네가 제안)
- 메카닉 무기·방어구 아이템은 중형·대형 몬스터와 탑 관리자에게서 드롭

### 5. 부위 강화 (확정 규칙, 그대로 구현)
강화 부위는 세력별 6곳:
- 메카닉: 머리, 팔, 몸통, 다리, 무기 슬롯, 방어구 슬롯
- 유전공학: 머리, 팔, 몸통, 다리, 손(무기화), 각반·발(방어)
부위별 스탯 (기본값은 네가 제안):
- 머리 = 치명타 확률, 팔 = 공격력, 몸통 = 최대 체력, 다리 = 이동 속도
- 메카닉 무기 슬롯 = 원거리 공격력, 방어구 슬롯 = 방어력 (장착 아이템의 기본 스탯 + 슬롯 강화 수치 보너스)
- 유전공학 손 = 근접 공격력·공격 속도, 각반·발 = 방어력
레벨 시스템은 없고 부위 강화로만 스탯이 오름.

강화 규칙:
- 부위마다 강화 수치를 가짐. 강화 수치 20마다 레벨 구간 1단계 (0~19 = 0구간, 20~39 = 1구간 ...)
- 최대 50구간 (강화 수치 1000)
- 강화 1회 시 해당 부위 재료 1개 소모. 성공 시 재료 등급에 따라 수치 상승: 일반 +1, 고급 +2, 희귀 +3, 전설 +5
- 상승분이 50의 배수를 넘으면 그 배수에서 멈춤 (예: 48에서 +3 → 50). 50의 배수는 건너뛸 수 없음
- 구간별 성공 확률과, 50의 배수를 넘는 시도(49→50, 99→100 등)에서 실패했을 때의 수치 하락:

  | 레벨 구간 | 강화 수치 | 성공 확률 | 50 배수 돌파 실패 하락 |
  | --- | --- | --- | --- |
  | 0~9   | 0~199   | 95% | -1 |
  | 10~19 | 200~399 | 80% | -2 |
  | 20~29 | 400~599 | 60% | -3 |
  | 30~39 | 600~799 | 40% | -5 |
  | 40~49 | 800~999 | 20% | -8 |
  | 50    | 1000    | 강화 불가 | - |

- 50의 배수 돌파가 아닌 일반 실패는 재료만 사라지고 수치 유지
- 오염 지역에서 사망 시: 무작위 부위 1곳의 강화 수치가 1~5% 감소 (그 지역 오염 농도에 비례). 감소로 레벨 구간이 내려갈 수 있음. 자기 세력 거점에서 부활
- 확률 보너스 배율(기본 1.0)을 코드에 미리 두고, 적용 확률은 최대 99%로 제한 (이후 탑 브레이크 보상 ×1.1용)

### 6. 거점 NPC와 퀘스트
- 각 세력 거점에 퀘스트 NPC 1명. 강화도 이 NPC에게서 진행
- 세력별 퀘스트 10개를 순서대로 진행하는 메인 퀘스트 라인
- 유형을 섞어서 구성: 특정 몬스터 처치, 부위 재료 수집, 지역 탐색(특정 지점 도달), 부위 강화 달성, 탑 특정 층 도달
- 난이도는 정글 → 해협 → 탑 순서로 자연스럽게 올라가게
- 보상은 재료(등급별)와, 메카닉은 장비 아이템
- 퀘스트 목록·대사·보상은 data 파일로 관리. 진행 중 퀘스트 목표를 화면에 표시

### 7. 탑 1~10층 (개인 진도)
- 탑 입구에서 입장. 클리어한 층의 다음 층까지 선택 입장 가능
- 층마다 테마가 다른 지능형 관리자 1명과 그가 부리는 몬스터 무리
- 미션 유형 3가지를 섞어서 배치:
  - 미궁형: 미로 구조를 탐색해 출구 도달 (제한 시간)
  - 퀘스트형: 관리자가 내는 과제 수행 (특정 오브젝트 파괴, 아이템 수집 등)
  - 사냥형: 몬스터 웨이브 처치 후 관리자 격파
- 10층은 강한 관리자 보스전
- 관리자는 고등급 재료를 드롭 (메카닉은 "외계 기술" 부품과 장비)
- 탑 안에서 사망하면 강화 수치 감소 없이 거점에서 부활, 해당 층은 다시 도전

### UI
- 상단: 체력 바, 세력 표시, 현재 지역, 진행 중 퀘스트 목표
- 강화 창: 6개 부위별 강화 수치, 레벨 구간, 현재 성공 확률, 보유 재료(부위·등급별), 강화 버튼, 성공/실패 결과
- 메카닉 장비 창: 무기·방어구 장착/해제
- 인벤토리, 퀘스트 창, 탑 층 선택 창
- 피격·처치·강화 결과에 간단한 피드백 (숫자 팝업, 깜빡임 등)

### 이번에 만들지 않을 것
서버, 계정, 멀티플레이, PvP, 파티, 채팅·거래, 탑 11층 이상, 탑 브레이크, 필드 자동 전투, 나머지 오염 지역(화산지대, 혹한지대), 수익화

### 완료 기준
- 두 세력을 각각 골라 시작할 수 있고, 원거리/근접 공격이 다르게 느껴진다
- 두 오염 지역의 몬스터 10종이 크기별로 다른 강함과 드롭을 가진다
- 세력별 6개 부위를 모두 강화할 수 있고, 메카닉은 무기·방어구를 장착할 수 있다
- 50의 배수 멈춤, 돌파 실패 하락, 사망 페널티(지역 농도 비례, 구간 하락 포함)가 규칙대로 동작한다 (강화 로직 단위 테스트 포함)
- 세력별 퀘스트 10개를 처음부터 끝까지 진행할 수 있다
- 탑 1~10층을 세 가지 미션 유형으로 클리어할 수 있고, 진도가 저장된다
- 새로고침해도 진행 상황이 유지되고, PC와 모바일 브라우저에서 모두 조작 가능하다
- 테스트용 디버그 메뉴: 재료 지급, 강화 수치 설정, 탑 층 해금, 퀘스트 건너뛰기
- 마지막에 실행 방법과 data/config에서 조정 가능한 값 목록을 README에 정리한다
