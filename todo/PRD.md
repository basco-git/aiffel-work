# Todo 앱 PRD

최종 수정: 2026-10-29

## 1. 개요

내 컴퓨터에서 도는 할 일(Todo) 앱이다. 먼저 로컬 무료 DB(SQLite)로 완성하고(길 A), 같은 앱을 클라우드 DB(Supabase)로 전환한다(길 B).

| 항목 | 내용 |
| --- | --- |
| 형태 | 웹 앱, 브라우저에서 `http://localhost:5000` (배포: https://basco-todo.onrender.com, 길 B) |
| 사용자 | 나 (길 B에서는 로그인한 사용자별로 분리) |
| 백엔드 | Python + Flask. DB 접근 코드는 백엔드에만 둔다 |
| 화면 | HTML + JavaScript. 백엔드 API(`/api/...`)만 호출한다 |
| 저장 | 길 A: 로컬 파일 `todo.db` (SQLite) / 길 B: Supabase (PostgreSQL) |

## 2. 기본 기능 (CRUD)

| 기능 | 설명 |
| --- | --- |
| 할 일 추가 | 제목(필수), 메모, 마감일, 태그 |
| 목록 보기 | 진행 중 / 완료 / 전체 탭 |
| 완료 표시 | 체크하면 완료 시각 기록, 해제 가능 |
| 미수행 시 기간 재설정 | 마감일을 새 날짜로 바꾸고 이유와 기록을 남김, 미룬 횟수 표시 |
| 삭제 | 확인 후 삭제. 태그 연결과 재설정 기록도 함께 삭제 |

## 3. 추가 기능

| 기능 | 설명 |
| --- | --- |
| 마감일 표시 | 오늘 마감은 주황, 마감 지난 미완료 일은 빨강 |
| 카테고리(태그) | 태그 여러 개 지정, 색 지정, 태그별 필터 |
| 오늘의 할 일 | 오늘 마감 + 마감 지남 + 직접 고른(☆) 미완료 일을 한 탭에 모아 봄 |
| 검색 | 제목·메모·태그 이름 부분 검색 (한글 포함) |

## 4. 저장 요구사항

- 앱(서버)을 껐다 켜도 할 일이 남아야 한다.
- 날짜는 날짜 형식(`YYYY-MM-DD`)으로 저장하고, 형식이 틀린 값은 거부한다.

## 5. 규칙

- 무료 도구만 쓴다. (Python, Flask, SQLite, Supabase 무료 플랜)
- 비밀값은 `.env`에 두고 git에 올리지 않는다. `todo.db`도 올리지 않는다.
- 로그인은 직접 만들지 않고 검증된 서비스(Supabase Auth)를 쓴다.

## 6. 길 A → 길 B

| | 길 A (로컬) | 길 B (클라우드) |
| --- | --- | --- |
| DB | SQLite 파일 `todo.db` | Supabase PostgreSQL |
| 로그인 | 없음 (나 혼자 사용) | Supabase Auth 이메일 로그인 |
| 데이터 보호 | 내 컴퓨터 안에만 있음 | RLS: 로그인한 사용자 본인의 행만 읽기·쓰기 |
| 전환 방법 | `.env`의 `DB_BACKEND=sqlite` | `.env`의 `DB_BACKEND=supabase` |

화면 코드와 API는 두 길에서 똑같다. 백엔드의 DB 계층만 바뀐다.

## 7. 완료 기준

- 길 A·길 B 각각에서 추가 / 완료 / 기간 재설정 / 삭제 / 검색이 동작한다.
- 길 A·길 B 각각에서 서버를 껐다 켜도 할 일이 남는다.
- 길 B에서 다른 사용자의 할 일이 보이지 않는다 (RLS 확인).
