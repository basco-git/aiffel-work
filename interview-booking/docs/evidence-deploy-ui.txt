# 배포 주소 제출 검증 (2026-11-03)

- 주소: https://basco-git.github.io/aiffel-work/interview-booking/
- 검증 방법: 배포 주소에서 공용 Chrome(헤드리스)으로 실제 화면 요소를 클릭하고, 시험 뒤 테스트 포지션을 삭제했어요.
- 시험 데이터: `[검증] <시각>` 포지션(삭제 완료)
- 결과: 3개 화면의 제출 성공 조건 **3/3 통과**

| 제출 조건 | 결과 | 실제로 본 것 |
|---|---|---|
| 1. 담당자 로그인 → 시간 후보 추가 → 새로고침 뒤에도 목록에 있음 | 통과 | 새로고침 뒤 시간 후보가 남아 있음 |
| 2. 면접관 2명이 같은 시간 체크 → 후보자 링크에 그 시간만 열림 | 통과 | 면접관 1·2 모두 가능 체크한 시간 후보가 예약 가능으로 보임 |
| 3. 후보자가 예약하면 다른 후보자는 마감, 담당자 화면엔 예약자 이름 | 통과 | 후보자 1 예약 → 후보자 2에 예약 버튼 없음·"마감" 표시 → 담당자 화면에 후보자 이름 표시 |

검증 뒤 테스트 포지션은 삭제했고, `[검증]` 제목의 포지션이 남아 있지 않음을 확인했어요. 실제 데이터는 쓰거나 지우지 않았어요.
