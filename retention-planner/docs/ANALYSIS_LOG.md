### 11-17 12:40-13:00 · 빠른 입력 막대 (사용자 요청)
- **문제:** 입력칸이 1단계 바로 위에 있어, 2단계 결과를 보면서 입력을 바꾸기 어렵다(사용자 의견).
- **검토한 방법:** 가) 2단계 위에 입력칸을 하나 더 나) 입력 팝업 링크 다) 따라다니는 입력 막대. 사용자가 다를 고름.
- **구현:** 위쪽 입력칸(#inputs)이 화면 위로 지나가면 화면 아래에 막대를 고정한다(IntersectionObserver). 막대에는 k·m 슬라이더(m은 인원 표시), 퇴사 1건 비용, 시나리오 A/B, "전체 입력 ↑", 접기 버튼이 있다. 막대 값은 위쪽 입력칸에 넣어 다시 계산하고, 위쪽 값은 막대에 반영한다. 시나리오 버튼은 기존 .seg 처리에 함께 묶여 위쪽 버튼과 연동된다.
- **확인:** 로컬에서 막대 표시·숨김, m 10% → 270명과 2단계 재계산, 시나리오 B 연동, 비용 입력, 접기를 확인했다. 콘솔 오류 없음, 730px 폭 가로 넘침 없음(브라우저 창을 390px까지 줄일 수 없어 그 폭은 직접 확인하지 못함). 웹 계산 대조 361개 통과. 화면 파일 버전 20261117e.
