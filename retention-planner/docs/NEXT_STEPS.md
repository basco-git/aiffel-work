# 다음 단계 제안서 — PoC에서 실제 도입까지

[문제 정의서](PROBLEM.md)와 [검증 결과](VALIDATION.md)를 바탕으로, 실제 회사에 도입하려면 무엇이 필요한지 정리했습니다. 교안 18번의 PoC 판정은 다음과 같습니다.
- **위험 점수 + 사유 맞춤 면담자 배정:** 시범 운영으로 진행
- **면담 효과 예측 모델:** 기록이 쌓일 때까지 보류

## 1. 단계별 계획

| 단계 | 기간 | 할 일 | 넘어가는 기준 |
| --- | --- | --- | --- |
| 0. 준비 | 1개월 | 개인정보·사내 규정 검토, 노사 협의. 사유 수집 방법 결정. 성공 기준 확정(아래 4절) | 법무·노무 검토 완료, 기준을 문서로 확정 |
| 1. 현행 수준 측정 | 3개월 | 지금 방식(인사 담당 면담)대로 하면서 면담 대상·면담자·사유·결과를 기록 | 기준선 퇴사율과 면담 기록 양식 확보 |
| 2. 무작위 시범 운영 | 6-12개월 | 위험 점수로 대상자를 고른 뒤 **추첨**으로 나눔: 면담 없음 / 위험 순 배정 / 사유 맞춤 배정 | 기간 중 규칙과 결과 정의를 바꾸지 않음 |
| 3. 평가 | 1개월 | 집단별 퇴사율·근속 기간·순이익 비교, 집단별(나이대·성별) 공정성 점검 | 4절 기준 충족 여부 |
| 4. 확대 또는 중단 | — | 기준을 넘으면 전사 적용. 기록이 수천 명 규모가 되면 면담 효과 예측 모델을 다시 검토 | 못 넘으면 이유를 기록하고 규칙 수정 후 2단계 반복 |

## 2. 필요한 데이터

| 데이터 | 용도 | 주의 |
| --- | --- | --- |
| 인사 기본 정보(직급, 근속, 승진 후 기간, 급여 상대 수준, 야근, 통근, 교육) | 위험 점수 | 나이·성별은 모델에 넣지 않고 공정성 점검에만 씀 |
| 퇴사 사유(연봉, 원하는 업무, 복지, 갈등, 회사 방향, **업무량**) | 면담자 배정 | **익명을 약속한 설문을 개인 선정에 쓰지 않음.** 사유는 면담(stay interview)에서 확인하거나 기명 동의를 받음. 팀장 갈등은 축소 보고되기 쉬움 |
| 면담 기록(대상, 면담자, 날짜, 확인한 사유, 면담 뒤 조치) | 효과 평가, 다음 모델 | 조치가 실제로 따랐는지가 핵심(실제 사례 D) |
| 결과(퇴사 여부, 퇴사 시점, 자발/권고 구분) | 채점 | **권고사직 등 회사 주도 퇴사는 분리**(실제 사례 A·F) |
| 무작위 배정 기록 | 면담 효과 추정 | 추첨은 인사팀이 아닌 시스템으로 |

이번 PoC에서 확인한 규모: 사유별 효과 차이가 크면 시범 기록 **약 9,000명**으로 효과 추정이 위험 순을 넘었습니다. 차이가 작으면 30만 명으로도 넘지 못했습니다. 중소기업 한 곳에서 이 규모를 모으기는 어렵습니다. 그래서 **규칙 기반 배정을 먼저 쓰고, 모델은 여러 해 기록이 쌓인 뒤**에 검토합니다.

## 3. 비용

| 항목 | 내용 | 비고 |
| --- | --- | --- |
| 면담 시간 | 팀장 면담 1건 30만 원, 임원 면담 1건 150만 원(가정) | 회사 값으로 바꿔 웹에서 계산 |
| 퇴사 1건 비용 | 3,000만 원(가정: 채용·교육·업무 공백) | 직급별로 다르게 넣는 것이 다음 개선 |
| 시스템 | 위험 점수 계산은 노트북 CPU로 몇 초. 웹은 정적 페이지라 서버 비용이 없음 | 외부 AI 서비스에 인사 자료를 보내지 않음 |
| 사람 | 인사 담당자의 기록 관리, 월 1회 점수 갱신 | 시범 기간 중 추가 업무 |

예시 조건에서 비용 기준 문턱은 퇴사 확률 3.3%였습니다(면담 비용 ÷ (성공률 × 퇴사 비용)). 면담이 싸면 많은 사람을 면담하는 쪽이 이득이고, 비싸면 문턱이 올라갑니다.

## 4. 성공 기준 (시범 시작 전에 확정)

교안 18번대로 **만들기 전에** 적어 둡니다. 숫자는 1단계에서 잰 현행 수준을 보고 0단계에서 확정합니다.

- **주 기준:** 사유 맞춤 배정 집단의 퇴사율이 위험 순 배정 집단보다 낮고, 순이익이 1.1배 이상일 것
- **안전 기준:** 팀장 갈등자에게 팀장 면담을 배정한 건수 0, 집단별(나이대·성별) 배정 비율에 설명할 수 없는 차이가 없을 것
- **보조 기준:** 퇴사까지의 근속 기간이 늘었는지(사례 D처럼 늦춘 효과)

## 5. 운영 원칙

| 원칙 | 이유 |
| --- | --- |
| 점수는 **면담 대기 순서**에만 쓴다. 개인 평가·징계·해고에 쓰지 않는다 | 실제 사례 F처럼 회사가 내보내려는 사람에게 쓰면 퇴출 도구가 됨 |
| 점수를 본인·동료에게 공개하지 않는다. 면담자에게는 "면담 요청"만 전달한다 | 낙인 방지 |
| 최종 판단은 면담하는 사람이 한다 | 이미 결심한 사람, 설문 밖 사유는 모델이 못 봄(검증 결과 2절) |
| 반복되는 사유는 제도 개선 과제로 넘긴다 | 연봉 역전(사례 B), 업무량(사례 E)은 한 사람 면담으로 해결되지 않음 |
| 규칙을 바꾸면 다시 일부를 무작위로 배정해 확인한다 | 바꾼 규칙이 실제로 나은지 알기 위해 |

## 6. 규칙·모델 개선 목록

| 개선 | 근거 |
| --- | --- |
| 사유 ⑥ **업무량** 추가, 면담자 권한 표에 "업무 재설계 권한" 추가 | 실제 사례 E |
| 회사 주도 퇴사를 대상에서 먼저 제외 | 실제 사례 A·F |
| 면담자 단계 세분화(팀장 / 실장·본부장 / 대표) | 실제 사례 D, 가상 실험에서는 두 단계뿐 |
| 결과를 퇴사 여부가 아니라 **근속 기간**으로도 평가(생존 분석) | 실제 사례 D(6개월 늦춤) |
| 임원 면담 자리가 모자랄 때 갈등자를 빠뜨리지 않는 규칙 | 실패 사례 ②: 규칙이 갈등자에게 아무 면담도 배정하지 못함 |
| "이미 결심" 신호 찾기(면담에서 확인한 이직 확정 여부 등) | 실패 사례 ①④: 임원 면담 41명 낭비 |
