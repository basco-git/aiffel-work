# site — 웹 시뮬레이터

비용과 인원을 바꿔 가며 "누구를, 누가 면담할지"의 순이익을 바로 보는 정적 페이지입니다. 외부 라이브러리 없이 HTML·CSS·JS와 인라인 SVG로 만들었습니다.

## 보기

```powershell
cd retention-planner
python -m http.server -d site 8000   # http://localhost:8000
```

파일을 더블클릭해 열면(`file://`) 데이터 파일을 읽지 못합니다. 위처럼 로컬 서버로 엽니다.

**배포할 때:** `index.html`의 `style.css?v=`, `app.js?v=`와 `app.js`의 `alloc.js?v=` 값을 함께 바꿉니다. GitHub Pages가 파일을 10분 동안 캐시하게 해서, 바꾸지 않으면 전에 열어 본 브라우저에 예전 화면이 보입니다(11-17).

**문구:** 화면 문구는 합니다체로 씁니다(11-17 사용자 결정).

## 화면 구성

1. 고지 (가상 데이터, 개인 평가 금지, 사유 데이터 출처 주의)
2. 입력: 대체 비용, 팀장·임원 면담 비용, 면담 성공률, 면담 대상 비율 k(%), 임원 면담 비율 m(%, 인원은 소수점 버림으로 칸 아래에 표시). "예시값 채우기"가 있습니다.
3. **1단계**(교안 17번): 방법 7개(기준선 2 + 모델 4 + TabICL)의 결과 카드(면담 안 하면 떠났을 사람 → 면담 후 재직(예상) / 면담 후에도 퇴사(예상), 면담 없이도 재직했을 사람, 예상 순이익과 계산식), 비용 기준 선택, 순이익 곡선, 비교표, 설명 카드(정확도 함정, AUC, 문턱)
4. **2단계**(교안 밖 확장): 시나리오 A/B 전환, 방법별 배분 결과(위험 순, 전문가 규칙, 효과 순, 최대치) — 면담 인원, 면담 후 재직(예상), 예상 순이익과 계산식, 역효과 우려, 최대치 대비, 순이익 곡선, 비교표, 업리프트 설명 카드
5. 분석 카드: Qini 곡선, 위험·효과 요인, 공정성 표, 신뢰도 곡선, 민감도 표
6. 한계와 윤리 체크리스트, 푸터(시드·버전·생성 시각)

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html`, `app.js`, `style.css` | 화면 |
| `alloc.js` | 계산 규칙. DOM이 없는 순수 함수라 Node에서도 돌아갑니다. 규칙은 [DATA_CONTRACT](../docs/DATA_CONTRACT.md)를 따릅니다. |
| `alloc.test.mjs` | `node alloc.test.mjs [데이터 폴더]`로 실행합니다. 손계산 예시와, Python 기대값(`data/reference.json`) 대조를 함께 합니다. |
| `data/` | `ml/run_all.ps1`이 `results/`를 복사한 실제 결과입니다. 직접 고치지 않습니다. |
| `mock/` | 화면 개발용 견본 데이터와 생성기입니다. 분석에는 쓰지 않습니다. |
