# evidence-capture: 확인 장면 캡처 스킬

과제 제출 문서에 넣을 "확인 장면" 이미지를, 실제 실행 결과 그대로 같은 모양으로 만드는 스킬입니다.

## 불편 → 해결

| 불편 (매번 반복하던 일) | 해결 (이 스킬) |
|---|---|
| 과제마다 터미널·Claude Code 장면을 캡처해 달라고 하면, 매번 HTML을 새로 짜고 이전 스타일 파일을 다시 찾아야 했음 (2026-11-02 C3·C4·C5) | 템플릿 `template.html`과 스타일 `base.css`를 스킬에 넣어 같은 모양으로 바로 시작 |
| 고정 높이로 찍어서 아래가 잘리고 다시 찍는 일이 반복됨 (C5를 330px로 찍었다가 잘려 385px로 다시 찍음) | 렌더 스크립트가 내용 높이를 먼저 재고 그 높이로 찍음 (같은 C5가 한 번에 379px로 나옴) |
| 확인창만 찍고 결과 화면을 빠뜨려 추가 캡처가 필요했음 (todo 길 B 삭제 장면) | 절차 첫 단계에 "결과가 보이는 화면인가" 확인을 넣음 |
| 다시 그린 화면인지 실제 캡처인지 문서에 밝히는 것을 잊기 쉬움 | 문서 표에 줄을 넣을 때 안내 문장에 번호를 함께 적도록 절차에 고정 |
| 공개 저장소 캡처에 이메일이 보여 나중에 가려야 했음 | 그리기 전에 개인정보를 가리는 단계를 넣음 |

## 언제 쓰나

- "캡처 찍어 줘", "확인 장면 만들어 줘", "스크린샷으로 남겨 줘", "C5 캡처 추가해 줘"
- 터미널 명령 결과, Claude Code 대화 장면처럼 직접 찍기 번거로운 장면

## 파일

| 파일 | 내용 |
|---|---|
| `SKILL.md` | 이름·설명·절차 (장면 정하기 → 실제 실행 → HTML → PNG → 문서 표에 추가) |
| `assets/template.html` | 터미널·Claude Code 장면 틀 |
| `assets/base.css` | 어두운 터미널 스타일 (C3~C5와 같은 모양) |
| `scripts/render.py` | 헤드리스 Chrome·Edge로 PNG 저장, 높이 자동 측정. `python -I render.py <html> <png>` |

## 원칙

다시 그린 화면은 편하지만 꾸며 낼 수도 있습니다. 그래서 이 스킬은 **이번 대화에서 실제로 실행한 결과만** 그리고, 실행할 수 없는 화면은 사용자에게 직접 찍어 달라고 하며, 문서에 "다시 그린 화면"이라고 밝힙니다.
