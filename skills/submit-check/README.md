# submit-check: 제출 전 점검 스킬

과제를 GitHub에 올리기 직전에 "빠진 거 없나"를 같은 기준으로 한 번에 확인하는 스킬입니다.

## 불편 → 해결

| 불편 (매번 반복하던 일) | 해결 (이 스킬) |
|---|---|
| 과제를 올릴 때마다 AI에게 "빠진 거 없나 봐 줘"라고 시키고, 그때마다 확인하는 항목이 달랐음 | 다섯 가지 점검을 스크립트로 고정해 매번 같은 기준으로 확인 |
| 2026-11-02 todo 7-1 제출 직전, 캡처에는 나오는 스킬 파일이 `.gitignore`(`.claude/` 전체 제외) 때문에 저장소에 아예 없던 것을 우연히 발견함 | 문서에 건 링크·이미지가 **실제로 git에 올라갔는지** 확인 (점검 1) |
| 공개 저장소에 사진을 올릴 때마다 개인정보·위치 정보를 따로 확인해 달라고 해야 했음 | 올라갈 이미지의 EXIF·위치 정보·텍스트 태그 자동 확인 (점검 3) |
| `.env`, 키가 섞여 올라갈까 봐 불안했음 | 올라갈 파일에서 키·토큰·비밀번호 형태 검사, 값은 출력하지 않음 (점검 2) |
| 맨 위 README 목록 갱신, PR 병합을 잊어 채점자 화면에 안 보일 뻔함 | 목록 링크와 `origin/main`에 아직 없는 커밋 확인 (점검 4·5) |

## 언제 쓰나

- "제출 전 점검해 줘", "올리기 전에 확인", "빠진 거 없나 봐 줘", "PR 만들기 전에 검사"
- 과제 폴더를 정리하고 커밋·PR 하기 직전

## 파일

| 파일 | 내용 |
|---|---|
| `SKILL.md` | 이름·설명·절차 (대상 정하기 → 스크립트 실행 → 표로 보고 → 확인 후 고치기) |
| `scripts/submit_check.py` | 점검 스크립트. 표준 라이브러리만 사용. `python -I submit_check.py <과제 폴더> --base origin/main` |
