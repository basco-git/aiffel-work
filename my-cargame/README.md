# Sky Drive 3D 🚗✈️

Three.js로 만든 3D 하늘을 나는 자동차 게임입니다.

**▶ 플레이: https://basco-git.github.io/aiffel-work/my-cargame/**

## 조작법
| 키 | 동작 |
|---|---|
| W / S | 가속 / 감속 |
| A / D, ← / → | 좌우 회전 |
| ↑, Space / ↓, C | 상승 / 하강 |
| Shift | 부스터 |
| P | 일시정지 |

황금 링을 통과해 점수와 연료를 얻고, 건물과 충돌하지 않게 비행하세요.

`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy-cargame.yml`)가 자동으로 GitHub Pages에 배포합니다.
