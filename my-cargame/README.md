# Sky Drive 3D 🚗✈️

Three.js로 만든 3D 하늘을 나는 자동차 게임입니다.

**▶ 플레이: https://basco-git.github.io/aiffel-work/my-cargame/**

## 조작법
| 키 | 동작 |
|---|---|
| W / S | 가속 / 감속 |
| A / D, ← / → | 좌우 회전 |
| ↑, Space / ↓, C | 상승 / 하강 |
| Shift | 부스터 |
| P | 일시정지 |

황금 링을 통과해 점수와 연료를 얻고, 건물과 충돌하지 않게 비행하세요.

`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy-cargame.yml`)가 자동으로 GitHub Pages에 배포합니다.

## 회고

- 퍼실님과 같은 프롬프트로 명령했지만 다른 결과.
- (퍼실님 : 클로드 데스크탑 앱, 나 : 클로드 CLI / 터미널 차이인지 궁금)
- 간단한 게임들은 claude 에서 쉽게 구현 가능하고, 빠진 요건들도 추천해줌.
- 명령 전 빠진 내용 들을 claude 에게 확인 후 진행하는 방법도 좋을 것 같음.
